# Deployment & Domain Setup Guide\n\n## Deploying to Vercel (Recommended)\n\n1. Push to GitHub\n2. Go to vercel.com/new\n3. Import `ootybpfc-website`\n4. Framework: Next.js (auto-detected)\n5. Click Deploy\n\n## Pointing ootybpfc.com to Vercel\n\n### Add Domain in Vercel\n1. Project Settings > Domains\n2. Add `ootybpfc.com` and `www.ootybpfc.com`\n\n### DNS Records\n\nRoot domain (`ootybpfc.com`):\n- Type: A, Name: @, Value: 76.76.21.21\n\nWWW subdomain:\n- Type: CNAME, Name: www, Value: cname.vercel-dns.com\n\n### SSL\nVercel auto-provisions free SSL via Let's Encrypt.\n\n## Post-Deployment Checklist\n- [ ] Site loads at https://ootybpfc.com\n- [ ] SSL active\n- [ ] www redirects to root\n- [ ] All sections render on mobile and desktop\n- [ ] Countdown timer works\n- [ ] No console errors\n
