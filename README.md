# Ooty Black Pearl FC \u2014 Official Club Website\n\nA modern, high-performance website for **Ooty Black Pearl Football Club (OOTYBPFC)**, built with Next.js, TypeScript, and Tailwind CSS. Features smooth scroll animations, a dark navy/green club aesthetic, mobile-first responsive design, and a professional football club UX.\n\n## Features\n\n- **Hero Section** \u2014 animated particle background, gradient text, scroll indicator\n- **Match Fixtures** \u2014 filterable list (all / upcoming / completed) with slide-in animations\n- **Countdown Timer** \u2014 live flip-digit countdown to the next match\n- **Training Programs** \u2014 3-tier pricing cards with hover effects\n- **Latest News** \u2014 featured + grid layout with category badges\n- **Player Spotlight** \u2014 player cards with animated stats\n- **League Table** \u2014 full Primer League standings\n- **Stats Counter** \u2014 animated counters that trigger on scroll\n- **Sponsors Section** \u2014 platinum & gold tiers\n- **Newsletter** \u2014 subscribe form in the footer\n- **Sticky Header** \u2014 transparent on top, frosted-glass on scroll\n- **Stripe Integration** \u2014 code present but disabled for future activation\n\n## Tech Stack\n\n| Layer | Technology |\n|-------|-----------|\n| Framework | Next.js 16 (App Router) |\n| Language | TypeScript |\n| Styling | Tailwind CSS 4 |\n| Animations | Framer Motion |\n| Icons | Lucide React + inline SVGs |\n| Payments | Stripe (disabled, code ready) |\n\n## Getting Started\n\n```bash\ngit clone https://github.com/ootybpfc/ootybpfc-website.git\ncd ootybpfc-website\nnpm install\nnpm run dev\n```\n\nOpen http://localhost:3000\n\n## Deploy on Vercel\n\nSee [DEPLOYMENT.md](./DEPLOYMENT.md) for full instructions.\n\n## License\n\nProprietary to Ooty Black Pearl FC.
